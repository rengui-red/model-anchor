\# 路线图



本文件定义每个未激活模块的\*\*接口定义、启动阈值、前置条件\*\*。没有阈值和接口定义的“预留”不算扩展准备。



\## v0.1（当前）



断点模板、minimal 打包、`--init`、过期检测、`load\_anchor` 函数边界。



\## v0.2



`hooks/stop-update.md`、`hooks/anchor-update.md`、`hooks/README.md`、4 个 model profile、full 与 task-scoped 模式、`stale.py` 独立模块。



\## 已定义、未激活的扩展模块



\### WebUI

\- \*\*接口定义\*\*：可视化编辑断点四字段，调用 `load\_anchor`/保存函数

\- \*\*启动阈值\*\*：≥3 个独立用户明确要求“可视化编辑断点”

\- \*\*前置条件\*\*：v0.2 的钩子/命令方案已被至少 10 个用户实际使用超过 2 周



\### MCP 服务器

\- \*\*接口定义\*\*：暴露 `get\_anchor` 与 `update\_anchor` 两个工具，读写 `断点.md`

\- \*\*启动阈值\*\*：用户反馈“不想配置钩子，希望 AI 直接调用工具读写断点”

\- \*\*前置条件\*\*：`anchor.md` 的机器可读约定已在 v0.1 固定，`load\_anchor` 边界已存在



\### 云端同步

\- \*\*接口定义\*\*：替换 `load\_anchor` 函数体为 HTTP 请求；断点文件可选云端备份

\- \*\*启动阈值\*\*：用户明确表达“跨设备使用同一份断点”需求，且愿意为此付费或接受备案带来的延迟

\- \*\*前置条件\*\*：本地版已有稳定用户群；若服务器在大陆，需完成 ICP 备案。\*\*备案是此模块的启动门槛，不是当前项目的负担\*\*



\### 新增档案层级（基线/规约/决策）

\- \*\*接口定义\*\*：`anchor.md` 的机器可读约定对任何一层通用；`load\_anchor` 增加层级参数

\- \*\*启动阈值\*\*：用户明确反馈断点之外的某一层也需要跨模型携带

\- \*\*前置条件\*\*：断点层的跨模型携带价值已被验证



\## 扩展接缝索引



| 接缝 | 位置 | 迁移方式 |

|---|---|---|

| 档案读取 | `packer/pack.py` 的 `load\_anchor()` | 只替换函数体 |

| 字段约定 | `anchor.md` 机器可读约定 | 已对全部层级通用 |

| 钩子传输 | `hooks/\*.md` 提示词 | prompt → http / mcp\_tool，语义不变 |

| 模型措辞 | `profiles/\*.md` | 新增文件，不改代码 |
