\## 11. `docs/04-钩子配置指南.md`



```markdown

\# 钩子配置指南



钩子的本质是\*\*提示词\*\*，不是代码。插件不写任何工具特定的集成代码，用户把提示词配到支持会话钩子的工具里即可。



\## Claude Code



将 `hooks/stop-update.md` 的内容配置为 Stop 钩子的提示词处理器（`prompt` 类型）。配置方法见 Claude Code 官方 hooks 文档。



\## Cursor



将 `hooks/anchor-update.md` 的内容配置为项目规则或自定义命令，在关键节点手动触发。



\## 通用方式（不配钩子）



不使用任何钩子时，用户可在关键节点把 `hooks/anchor-update.md` 的内容粘贴给任意 AI，让其按模板更新断点。这是最小可用路径，不依赖任何工具特性。



\## 迁移路径（已定义，未实现）



Claude Code 的 hooks 支持多种处理器类型：`command`、`http`、`mcp\_tool`、`prompt`、`agent`。本插件当前以 `prompt` 形式提供。若未来有自建服务，可等价迁移为 `http` 类型，请求体格式参考 `stop-update.md` 的提示词结构；若未来做 MCP 服务器，可迁移为 `mcp\_tool` 类型。提示词语义不变，只换传输层。
