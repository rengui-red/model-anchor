ModelAnchor 是一个模型无关的通配档案层。解决大模型会话遗忘、额度断连、跨模型风格错乱。一套档案格式，多端运行，让你的每一次对话，都拥有持久的记忆基线。

下载体验 v0.1.0

为什么选择 ModelAnchor？

🌉

模桥通配

不绑定任何单一模型。无论是 Claude、DeepSeek 还是千问、豆包，统一输出接续提示词，真正做到即插即用，无缝切换。

🛡️

基线不丢

将项目定位、核心红线、当前断点固化为纯 Markdown 档案。避免 AI 在长会话中产生“遗忘”甚至推翻既定的技术决策。

⚡

极致轻量

无后端、无数据库、零外部依赖。仅靠 Python 标准库与本地文件运行。数据 100% 存储于您的本机，安全私密。

三步极速接入

# 1. 在项目根目录初始化断点档案
python packer/pack.py --init

# 2. 将断点打包为目标模型的专属 Prompt（例如打包给豆包）
python packer/pack.py --model doubao --minimal

# 3. 复制终端输出的结果，直接粘贴到任意大模型的对话框，即刻接续开发！
